# 累计检测额度

普通账号从本次更新起累计最多成功生成3份报告。失败或取消不扣，进行中任务预占名额，同一请求重试不重复计次，删除报告不返还次数，新检测和增量补跑使用同一额度。管理员角色及原四个精确匹配的本地测试身份继续豁免。

`paper_lint_quota_policy` 只有id=1一行。首次初始化使用UTC ISO时间写入starts_at，后续初始化使用INSERT OR IGNORE保持原值。起点前提交的任务，包括上线前已完成和跨上线完成的任务，均不占新额度。不能在日常部署、重启或维护时删除/更新此行，否则会重置额度。

额度读取和原子INSERT准入均按该起点过滤任务；不再使用日期窗口。接口返回period=lifetime、starts_at及day/resets_at=null。耗尽成功报告额度不再返回Retry-After；临时占用仍可30秒后重查。内部原有Daily命名保留以减小调用面，不代表每日重置。

上线前对真实数据库只读备份的隔离副本迁移两次，确认旧表内容不变、全部旧任务不计次、起点不变。发布器会停服务后初始化正式数据库，正式起点以首次新版本初始化时间为准。两台服务器数据独立，分别记录各自上线起点。

不修改检测器、提示词、输入、任务完成/取消事务、收件策略、原检测说明或报告布局。
