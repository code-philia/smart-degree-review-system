## 目标与上下文

把 paper 看作可编译的代码：PDF 解析为有类型的论文结构树和语义关系；标题、章节、Method、引用和文献条目是节点，节点含子节点。引用类似函数调用，具有绑定、外部资源身份和具体用途的语义约束。

论文表示分为 Layout IR、Document AST 与 Semantic Graph，分别保存版面来源、文档结构树和语义关系。

```text
PDF → 共享 Paper Model 下的 Paper IR（结构树＋符号表＋语义关系）
自然语言规则＋规范 → 大模型 API 编译为 IR 检查程序
IR 变异及合规对照 → 另行验证 → 冻结数据与标签
检查程序检测 IR → 反馈集误报／漏报／失败 → API 修订模型及代码
    → 重建受影响 IR → 重新检测 → 验证集选版本 → 独立测试
    → 用户查看结果、确定上线要求 → 验收 → 首次发布
上线后每次用户输入 → 当前共享版本解析和检测 → 判断 freeze 开关
    freeze=false（默认）：自动验证反馈 → 修订模型与程序 → 重建 IR、复检和回归
        → 验证通过后启用新版本 → 本次及后续输入继续使用与迭代
    freeze=true：锁定当前兼容版本输出报告，不进入修订或候选晋级
```

快速扩展依靠共享表示、规则编译器和通用反馈循环，而不是人工逐条开发检测器。30／300 条规则是扩展目标；本轮只实验 R31—R33，不提前声称已经验证大规模扩展。
