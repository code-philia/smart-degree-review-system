# 论文上传页紧凑布局

## 目标与范围

用户认为上传页空旷，希望改善整体美感。沿用现有蓝白色、字体、导航与页面操作顺序，仅调整上传页的视觉层次和间距。

## 方案选择

- 用户选择紧凑单栏：保留现有结构，缩短上传区并优化层次。
- 未采用左右双栏：它可以分离操作和说明，但用户希望保留单栏结构。

## 具体设计

- 内容宽度与历史报告页统一为最大 1152px；标题保留现有字号和副标题，不恢复已移除的小标题。
- 用户在 184px 本机预览上要求适度加高上传框。桌面最小高度调整为 216px，窄屏为 192px；图标缩为 48px，收紧其与正文的间距，使用浅蓝灰底和轻边框。
- 两个步骤编号采用统一的浅蓝小方形底；标题、计数和操作在各自行内对齐，规则仍默认收起。
- 底部说明整理为低对比浅蓝提示区，加“检测说明”标题，保留完整文案及 14px 字号、28px 行距。
- 保留上传、拖拽、移除、规则选择、开始/停止、恢复任务及实时报告行为。

## 验证

按用户选择的单栏方案与加高要求修改组件。回归上传与规则选择、任务进度和历史页相关测试；浏览器检查桌面与窄屏、长文件名、规则展开和运行状态。
